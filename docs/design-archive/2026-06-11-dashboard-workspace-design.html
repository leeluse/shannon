01 · 문서 소개
이 문서에 대해
v1-scope/dashboard 브랜치에서 추가 설계가 필요한 화면 3종의 UI/UX 명세입니다. 기존 Sidebar와 5-Step Modal은 다루지 않으며, 배포 이후 사용자에게 보여지는 결과 화면을 다룹니다.
설계 범위
  • ✦ Dashboard Home (InitPanel 대체)
  • ✦ Generation View (배포 → 결과 전환)
  • ✦ Project Workspace (워크플로우 + 상세)
  • ✦ 신규 컴포넌트 5종
  • ✦ 신규 CSS 토큰 4개
설계 원칙
  • ✦ Progressive Disclosure — 필요한 만큼만
  • ✦ 기존 .glass / .glass-modal 패턴 유지
  • ✦ c-lav (#DDB7FF) 중심 강조 체계
  • ✦ 폭포수 단계 구조로 AI 결과물 시각화
