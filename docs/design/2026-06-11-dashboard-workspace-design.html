01 · 문서 소개
이 문서에 대해
Shannon v1-scope/dashboard 브랜치에서 추가 설계가 필요한 화면 3종의 UI/UX 명세입니다. 기존 구현된 레이아웃 (Sidebar, 5-Step Modal)은 다루지 않으며, 배포 이후 사용자에게 보여지는 결과 화면 전체를 다룹니다.
설계 범위
  • ✦ Dashboard Home (InitPanel 대체)
  • ✦ Generation View (배포 → 결과 전환)
  • ✦ Project Workspace (워크플로우 + 상세)
  • ✦ 신규 컴포넌트 5종
  • ✦ 신규 디자인 토큰 2종
설계 원칙
  • ✦ Progressive Disclosure — 필요한 만큼만 표시
  • ✦ 기존 glassmorphism 패턴 유지
  • ✦ c-lav(#DDB7FF) 중심 강조 체계 일관 적용
  • ✦ 폭포수 단계 구조로 AI 결과물 시각화
